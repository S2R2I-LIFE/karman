Quick Tasks

Scenario: BGP Neighbor Not Establishing

Problem: BGP neighbor relationship stuck in "Active" or "Idle" state

Goal: Diagnose and fix BGP neighbor connectivity issues

Command Workflow Path:
1. EnableMode 2. show bgp summary 3. show bgp neighbors 4. ConfigSessionMode 5. RouterBgpBaseMode
Command: address-family
Configuration BGP Routing Requires Privilege 15
Syntax:
[no|default] address-family <ADDR_FAMILY> [no|default] address-family flow-spec <AF> [no|default] address-family link-state [no|default] address-family mvpn-ipv4
Description:

Enters BGP address family configuration mode to configure address-family specific parameters like neighbors, networks, route policies, and redistribution.

When to Use:
  • Configuring IPv4/IPv6 unicast or multicast routing
  • Setting up VPNv4/VPNv6 for MPLS L3VPN
  • Enabling EVPN for VXLAN overlay networks
  • Configuring route filtering per address family
Common Use Cases:
Scenario 1: Configure IPv4 unicast BGP
address-family ipv4 unicast
Scenario 2: Enable EVPN for data center fabric
address-family evpn
Example Output:
Router(config)# router bgp 65000 Router(config-router)# address-family ipv4 unicast Router(config-router-af)# network 10.0.0.0/8 Router(config-router-af)# neighbor 10.1.1.1 activate
Parameters
Parameter Description
ADDR_FAMILY Address family type:
• ipv4 unicast
• ipv6 unicast
• evpn
• vpnv4
• vpnv6
no Remove config
default Reset to default
Important Notes
  • Must be in BGP router config mode first
  • Changes require "neighbor activate"
  • Clear BGP session after major changes
Related Commands:

• show bgp summary

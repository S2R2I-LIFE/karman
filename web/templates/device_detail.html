This page gives you a deep view into a single device. It is split into three tabs so that running show commands doesn't push telemetry data off-screen.

Kármán connects to the device using whichever management type was configured — eAPI, SSH, or gNMI — so not every feature is available on every device.

Overview tab — device facts (model, version, serial), applied configlets, and custom tags.
CLI tab — run any EOS show command directly from the browser. Output is syntax-highlighted and stays within its own scrollable pane.
Telemetry tab — interface up/down history and link-flap counts from Prometheus. Only visible on gNMI-managed devices.
Test Connection — verifies that Kármán can reach the device right now using the configured management type.
Telemetry range — use the 1h / 6h / 24h buttons to change the time window shown on the interface chart.
Tags — free-form labels you can attach to devices for filtering and grouping in future workflows.

Device Inventory

The Device Inventory is the source of truth for all network devices managed by Kármán. Every device you add here becomes available for telemetry polling, CLI command execution, configlet deployment, and task tracking.

Each device is assigned a management type that tells Kármán how to communicate with it. Use the Detect button on the Add Device form to automatically probe which protocols are reachable.

eAPI (HTTPS·443) — Arista's REST API. The most feature-rich option; returns structured JSON for all show commands.
SSH (port 22) — traditional CLI access via Netmiko. Works on any device; output is plain text.
gNMI (port 6030) — streaming telemetry via TerminAttr. Required for the Interface Telemetry tab on the device detail page.
CVP — device is managed by CloudVision Portal. Kármán defers configuration changes to CVP for these devices.
Site — a free-text label used to group devices on the Dashboard. Typically a location code such as DC1 or LON.
Container — the CVP container this device belongs to (e.g. Undefined, Spine). Used for CVP-managed workflows.

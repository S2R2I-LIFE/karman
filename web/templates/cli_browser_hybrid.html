CLI Browser Hybrid Navigation

The CLI Browser is an interactive reference for the full Arista EOS command set — over 20,000 documented commands covering every feature area. Use it to look up syntax, understand available options, and build commands step by step before running them on a live device.

Commands are organised by technology (BGP, OSPF, VLANs, etc.) and by action (show, configure, clear, debug) so you can narrow down to exactly what you need without knowing the full command upfront.

Semantic search — type a concept (e.g. "bgp neighbor" or "interface errors") and the browser returns the most relevant commands ranked by relevance.
Technology tabs — jump directly to BGP, OSPF, Interfaces, VLANs, ACLs, QoS, and more without typing anything.
Action filter — narrow results to Show, Configure, Remove, Clear, or Debug commands depending on what you're trying to do.
Progressive builder — click a command template to open the step-by-step builder. It guides you through required keywords and parameters one token at a time.
Copy to clipboard — once the command is complete, copy it with one click and paste it directly into the CLI tab on any Device Detail page.
Ready to use badges mark commands that have no required parameters — you can run them as-is.

Change Control Tasks

Tasks are the audit trail for every configuration change made through Kármán. Any time a configlet is applied, a CLI command is pushed, or a bulk operation runs, a task is created to track it from start to finish.

Tasks give you a controlled, reviewable workflow — you can see exactly what was sent to a device, what the device returned, and whether the operation succeeded or needs attention.

Pending — task has been created but not yet executed. You can review and cancel it before it runs.
Running — task is actively connecting to devices and pushing configuration. Live logs appear in real time.
Completed — all devices responded successfully. The full output log is preserved for auditing.
Failed — one or more devices returned an error. Open the task to see per-device logs and diagnose the issue.
Logs — every task stores a timestamped log of exactly what was sent and received, so you have a full change record.
Filter — use the status tabs above the list to focus on Pending, Running, or Failed tasks that need attention.

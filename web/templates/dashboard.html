Dashboard Network Overview

The Dashboard is your live network overview. It polls every device every 30 seconds and displays real-time telemetry — reachability, CPU, memory, temperature, and interface counts — without you having to open each device individually.

Devices are grouped by site prefix (the leading segment of the hostname, e.g. DC1 from DC1-spine1). Sites with DOWN or degraded devices are automatically expanded and pinned to the top.

Credentials — set your device username/password once per session. They are stored only in the browser and never sent to the server until a poll runs.
Sort — order devices by priority, hostname, CPU, memory, temperature, or interface-down count.
Group — choose flat (no grouping), auto (group by hostname prefix), or custom (your named groups). Custom groups show status dots when collapsed.
Compact / Normal — switch between a dense 4-per-row card layout and a detailed 2-per-row view.
Temperature — click any temperature badge to toggle between °C and °F across all cards.
Sections — each panel (Summary, Telemetry, Charts, Actions) can be collapsed independently. State is saved per browser.

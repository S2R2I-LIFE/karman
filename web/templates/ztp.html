Zero Touch Provisioning

Zero Touch Provisioning (ZTP) lets new Arista switches automatically configure themselves and register with Kármán the moment they boot — no manual intervention required.

When a switch boots without a startup config, EOS enters ZTP mode, sends a DHCP request, and downloads and executes a script from the URL returned in DHCP Option 67. Kármán serves that script and accepts the registration callback.

Built-in DHCP — Kármán can run its own dnsmasq DHCP server. Requires dnsmasq on the host and network_mode: host in Docker Compose.
Existing DHCP — point your current DHCP server's Option 67 to the ZTP Script URL shown at the top of this page. No built-in DHCP needed.
API Key — optional pre-shared key baked into the ZTP script. If set, only scripts with the correct key can register devices.
Base Config Template — the EOS config written to every new device. Supports {username}, {password}, {hostname}, {ip}, and {karman_url} variables.
Auto-Registration — when a device calls back, Kármán probes its ports, selects the best management type, and adds it to the inventory automatically.
Active Leases — shows all DHCP leases issued by the built-in server. Pending devices can be manually registered from this table.

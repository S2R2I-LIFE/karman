Configlets

A configlet is a reusable snippet of EOS configuration. Instead of typing the same block of CLI on every device, you write it once, parameterise it with Jinja2 variables, and apply it to as many devices as needed.

Configlets can be assigned to individual devices or to a container of devices. When applied, Kármán renders the template with each device's variables and pushes the resulting configuration via the device's management connection.

Jinja2 templating — use {{ "{{" }} variable {{ "}}" }} syntax to substitute per-device values such as IP addresses, ASNs, or interface names.
Preview — render the configlet with sample variable values before applying it to a live device.
Validate — Kármán checks the configuration syntax before pushing, reducing the risk of a bad commit.
Assign to devices — open a configlet and use the Assign button to link it to one or more devices from the inventory.
Tasks — applying a configlet creates a Task that you can track, approve, and roll back from the Tasks page.
Version history — every edit is logged so you can see what changed, when, and who made the change.

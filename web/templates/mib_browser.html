What is a MIB?

A Management Information Base (MIB) is a formal database of managed objects on a network device. Each object has a unique numeric identifier called an OID (Object Identifier) and describes a single measurable value — such as an interface counter, a temperature reading, or a BGP session state. MIBs are written in SMIv2 (ASN.1 notation) and are the foundation of the SNMP protocol, which network management systems use to query or configure devices.

Arista ships a set of vendor-specific MIBs that extend the standard IETF MIBs with EOS-specific data — hardware TCAM utilisation, gNMI connectivity monitoring, PFC watchdog counters, and more. Use this browser to explore those objects, understand what data each OID exposes, and identify the right OIDs before configuring an SNMP poller or writing a monitoring script.

Common use cases
Real-time monitoring
Poll counters and gauges with tools like Prometheus SNMP Exporter, Zabbix, or LibreNMS to build dashboards and alerts.
ARISTA-IF-MIB · ARISTA-ENTITY-SENSOR-MIB · ARISTA-HARDWARE-UTILIZATION-MIB
Security & ACL auditing
Read per-rule hit counters to verify which ACL entries are active and detect unexpected traffic patterns.
ARISTA-ACL-MIB · ARISTA-IF-MIB (inAclDrops)
Routing health
Track BGP session state, neighbour counts, and prefix advertisements for EVPN/IP fabric monitoring.
ARISTA-BGP4V2-MIB · ARISTA-VRF-MIB
Environmental alerts
Receive SNMP traps when a temperature sensor crosses a threshold or a fan enters a fault state.
ARISTA-ENTITY-SENSOR-MIB · ARISTA-REDUNDANCY-MIB
Capacity planning
Track high-water marks on TCAM, MAC tables, and ECMP groups before you hit hardware limits.
ARISTA-HARDWARE-UTILIZATION-MIB · ARISTA-QUEUE-MIB
Optical & PHY health
Monitor pre/post-FEC bit error rates and uncorrected codewords to catch degrading optics before they fail.
ARISTA-PHY-MIB · ARISTA-XCVR-DWDM-MIB
Object types in this browser

TEXTUAL-CONVENTION  A named type alias (e.g. InterfaceIndex, TruthValue) used across multiple objects.
OBJ IDENTIFIER  A structural node in the OID tree — not polled directly, used for namespacing.

Switch Ingest

Switch Ingest bridges an unprovisioned or factory-reset Arista switch to Kármán using the karman-link agent running on a laptop directly cabled to the switch's Management0 port.

Run the agent on your laptop and it appears here automatically. Choose a workflow — New Switch if it's factory-reset, or Adopt Existing if it's already configured and reachable. Both flows push the EOS configuration Kármán needs, then add the device to your inventory.

karman-link — run python karman_link.py --server <url> --key <key> on your laptop. It auto-discovers the switch at 192.168.0.1.
New Switch — factory-reset switch cabled directly to your laptop. Kármán logs in as admin (no password) and configures management IP, eAPI, SSH, and optionally TerminAttr.
Adopt Existing — switch is already on your network. Provide credentials and Kármán pushes only the missing eAPI / SSH / TerminAttr config needed for telemetry.
Ingest — collects show version, interfaces, LLDP, running-config, environment, and BGP from the switch for inventory enrichment.
Add to Inventory — after provisioning and ingest, add the switch to Kármán's device list with one click. Pre-fills hostname, IP, model, and serial automatically.
API Keys — generate keys in Admin → Agent Keys. Each key authorises one agent to connect. Revoke keys that are no longer in use.
Lab / EVE-NG — run karman-link on the EVE-NG host directly. Use --switch-ip to target any vEOS node. For the New Switch flow the node needs eAPI HTTP already listening — add this minimal startup config: 
management api http-commands
   protocol http
   no shutdown
interface Management0
   ip address 192.168.100.50/24
ip route 0.0.0.0/0 192.168.100.1

How to use karman-link
  1. Generate an API key on the Agent Keys page.
  2. Cable your laptop's ethernet to the switch's Management0 port.
  3. Run: python karman_link.py --server {{ request.host_url.rstrip('/') }} --key <api_key>
  4. The agent appears below once connected. Click Start Ingest to collect data.
